# Bundled animations

`shinjuku-rain.mp4` is the default animation, 「新宿决战」雨爱版, approximately 110 seconds at 1920×1080 / 30 fps. The provider confirmed public distribution authorization for the video, visuals and music on 2026-10-17. See [MEDIA-NOTICE.txt](MEDIA-NOTICE.txt) and [bundled-video.json](bundled-video.json) for provenance and checksums. It is a separate media asset; the software license does not grant further media rights.

The source supplied was about 196 MiB. The distribution copy preserves resolution, frame rate and the original AAC audio stream and uses H.264 CRF 22, maxrate 5M / bufsize 10M. The original file was not modified. The roughly 62 MiB distribution file is hosted as a GitHub Release asset rather than committed to Git. Run `../Download-BundledMedia.ps1` before the first source build to obtain and verify it.

## Generated backup test animation

`sample.mp4` is a six-second 1280×720 H.264 test pattern generated by FFmpeg's `testsrc2` source. It contains no third-party animation, music, branding or personal media. Its generation command is in `../Generate-Sample.ps1`; only the resulting video is distributed, not FFmpeg. It is included as a functional test resource under the project's PolyForm Noncommercial 1.0.0 terms.

Run `Generate-Sample.ps1 -FFmpeg <path-to-ffmpeg.exe>` to regenerate it. The checked-in SHA-256 records the current asset; codec versions can change binary output.
